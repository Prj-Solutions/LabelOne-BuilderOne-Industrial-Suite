BuilderOne is a low-code/no-code application builder and runtime environment for industrial end-of-line terminals, touchscreen HMIs, and weighing/labeling stations. It serves as a lightweight, cross-platform alternative to **NiceLabel PowerForms**, **Loftware BarTender Print Station**, and **Siemens WinCC**.

---

## 1. No-Code Visual Configuration (Visual HMI & Direct Printing)

For standard industrial packaging and labeling lines, BuilderOne requires **zero code**. Operators and system integrators configure the interface purely through visual objects and property binding:

- **Visual Data Selection**: Drop-down lists, search tables, and database record selectors.
- **Manual Data Entry & Flags**: Touchscreen numerical keypads, text inputs, and dynamic checkboxes for batch/lot options.
- **Dynamic Label Preview**: Real-time rendering of the label generated by the **LabelOne** engine directly on the HMI screen.
- **Direct-to-Printer Action**: Attaching a "Print" command to a visual button automatically routes RAW commands (ZPL, TSPL, SBPL, Direct Protocol) to thermal printers without writing driver or network code.

## 2. Low-Code Scripting Engine (Rhino JavaScript / Java Integration)

When custom business logic is required—such as parsing database records, exporting tabular data, performing weighing calculations, or dynamic string manipulation—BuilderOne embeds a flexible JavaScript engine interacting seamlessly with underlying Java libraries and native API handlers (`libAction`, `libVar`).

### Real-World Scripting Example: Exporting Database Records to Unicode CSV

Below is an embedded Rhino JavaScript snippet used within a BuilderOne event to connect to an embedded HSQLDB database and export operator records directly into a TSV/CSV Unicode file:

```javascript
// ************************************************************
// BuilderOne Event Script: Export Operators Master Data to CSV
// ************************************************************

var dbg = 0;
var errorMessageText = "No records found to export";

// Helper function to render on-screen HMI display error
function showDisplayError(message) {
    libAction.errorMessage_(message);
}

// MAIN Execution Loop
try {
    var format = new java.text.SimpleDateFormat("dd.MM.yy HH:mm");

    // BuilderOne native method: Establishes database connection
    // Type 12 = HSQLDB embedded database located inside the "Data" folder
    var pathDB = libAction.getAbsolutePath("users.properties", "Data");
    if (dbg) {
        print("pathDB: " + pathDB + "\n");
    }

    var con = libVar.setConnection(12, pathDB);
    if (con != null) {
        var pNumRecord = 0;

        var st = con.createStatement();
        var rs = st.executeQuery("SELECT * FROM \"users\"");
        var rsmd = rs.getMetaData();

        // Export Unicode TSV/CSV file to the "Data" folder
        var out = libAction.writeFileUnicode(theApp.libAction.getAbsolutePath("ANAGRAFICA.csv", "Data"));
        
        var header = "";
        var columnCount = rsmd.getColumnCount();
        var tot = rsmd.getColumnCount();

        // Build CSV Table Header
        for (var i = 0; i < tot; i++) {
            header += rsmd.getColumnName(i + 1);
            if (i < tot - 1) {
                header += "\t";
            }
        }
        header += "\r\n";
        out.print(header);

        // Loop through database records
        while (rs.next()) {
            pNumRecord++;
            var row = "";
            for (var i = 0; i < tot; i++) {
                var field = rs.getString(i + 1);
                if (field == null) {
                    field = "";
                }
                row += field;
                if (i < tot - 1) {
                    row += "\t";
                }
            }
            row += "\r\n";
            out.print(row);
        }
        out.close();

        // Validate exported record count
        if (pNumRecord == 0) {
            showDisplayError(errorMessageText);
        }
    }
} catch (error) {
    showDisplayError("<html>Error exporting Master Data:<br>" + error.message + "</html>");
}
