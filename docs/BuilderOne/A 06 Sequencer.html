Pulsante Sequencer

Consente di eseguire le azioni presenti in un frame, o di eseguire una sequenza di azioni esterne al frame. Cliccare sul menu "Sequencer" nella sezione "Azioni" del pannello "Componenti" (1), poi portarsi con il mouse sul Frame_2 (2), e cliccare per inserire il pulsante (3).

 Il pulsante Sequencer per default riporta l'etichetta Start, ma tale etichetta può essere cambiata. Per default inoltre la lista di azioni è vuota. Questo implica che verranno eseguite le azioni presenti nel frame. Nel nostro caso l'esportazione dei dati inseriti nelle due finestre Lotto e Note.

Per controllare il contenuto dei due file Lotto.txt e Note..txt possiamo usare delle "Sentinelle". Nel pannello "Componenti", nella sezione "Sentinelle", troviamo Monitor di File.
