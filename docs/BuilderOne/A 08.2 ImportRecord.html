Importare da File in un record di una tabella

Vediamo ora come sia possibile importare nei campi di un record valori presenti in file.

Useremo la stessa tabella del database creato per HelloWorld. Aggiunguamo una riga nella sequenza Table_IO.

 

Nel pannello delle Proprietà selezioniamo Files->Table

 

Clicchiamo alla destra di destinazione per settare il database e la tabella in cui importiamo.

 

Selezionimao il tipo di formato del database

 

Selezioniamo il database

 

Selezionimao la tabella

 

Ora bisogna settare i parametri per l'importazione. Cioè da quale file vogliamo importare e in quele campo del record vogliamo scrivere.

cliccando due volte nella colonna (sorgente) e nella colonna (desrtinazione) potremo selezionale il file da cui prelevare il valore e il campo in cui scrivere. E' anche possibile inserire una formula per manipolare, se necessario, il dato prima di importarlo. La selezione del record verrà fatta cercando il record il cui campo ID ha lo stesso valore contenuto nel file "database_Tabella_ID.txt".
