Macro

Le Macro sono una serie di componenti che consentono di completare il Vostro progetto. Per mostrare come queste possano essere usate realizziamo un frame che chiameremo "Configurazioni".

Keyboard Enabler

Consente di usare una tastiera virtuale che si aprirà automaticamente quando si cliccherà su un campo di inserimento testo. Tale tastiera sarà di tipo numerico o alfanumerico in base alle caratteristiche dalla finestra di inserimento del testo. La tastiera virtuale può essere configurata definendone la dimensione, il font e la lingua. Per configurare la tastiera e necessario usare il pulsante relativo nella barra dei menu.

 

Cliccare sul menu Keyboard Enabler nella sezione "Macro" (1), poi portarsi con il mouse sul Frame (2), e cliccare per inserire il Componente (3).

Gestore Buckup

Il gestore dei backup è un utile e irrinunciabile componente che consente di fare il backup dei dati presenti nella cartella Data tutte le volte che il progetto viene chiuso. Tale backup viene inserito in una cartella che verrà chiamata Data_Backup_N dove N è il giorno della settimana. In questo modo sono disponibili 7 backup per i sette giorni della settimana. Dopo 7 giorni i Backup si sovrascrivono a quello relativo al girno della settimana precedente.

Cliccare sul menu Gestore Backup nella sezione "Macro" (1), poi portarsi con il mouse sul Frame (2), e cliccare per inserire il Componente (3).

Con il pulsante"<" è possibile configurare la cartella dove deve essere fatto il backup. Questa operazione deve essere fatta in fase di utilizzo del programma, non in fase di editing del progetto. Quidi dal Cliente si decide se Il backup deve essere fatto nella cartella di default del progetto, oppure in una cartella indicata dal cliente.

Se non viene fatta alcuna selezione, la cartella in cui verrà fatto il beckup sarà la cartella del progetto.

Per fare il Backup può essere scelto anche un server in rete. Inoltre Oltre al backup automatico di ogni giorno è possibile effettuare un backup su richiesta, premendo il pulsante "Backup Ora". In tal caso il programma chiede in quale cartella fare il backup.

 

 

Gestore Login

Il gestore LogIn consente di aggiungere o di eliminare uno user dall'elenco.

Cliccare sul menu Gestore Login nella sezione "Macro" (1), poi portarsi con il mouse sul Frame (2), e cliccare per inserire il Componente (3).
