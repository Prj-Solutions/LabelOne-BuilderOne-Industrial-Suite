Creare il Pacchetto di Installazione

LabelOne e i suoi Progetti non necessitano di una vera e propria installazione. L'installazione, infatti, consiste nel copiare la cartella di LabelOne nel PC ospite. Tutte le librerie, dll, e risorse necessarie al programma sono contenute i questa cartella. Nulla è messo al di fuori di tale cartella.

Restano però alcune difficoltà nel lanciare l'applicazione. Se infatti si deve eseguire LabelOne, basterà un doppio click su L1.jar, ma se si deve eseguire Builder One oppure un progetto bisognerà creare un link che permette di eseguire L1.jar con i relativi "argomenti" o parametri di esecuzione.

Per eseguire LabelOne è sufficiente javaw.exe -jar percorso\L1.jar
Per eseguire BuilderOne è sufficiente javaw.exe -jar ercorso\L1.jar -PED
Per eseguire il progetto HelloWorld è sufficiente javaw.exe -jar percorso\L1.jar HelloWord.prj Frame_1.spj

Dove percorso rappresenta la path completa della cartella dove si trova L1.jar.

Ulteriori parametri di esecuzione servono a specificare la quantità di memoria da usare -Xmx128m, eventuali patch della JVM -Xbootclasspath/p:"Patch\rt.jar", la posizione delle librerie da usare -Djava.library.path="Sys\Windows" -Djava.ext.dirs="Library"

Per evitare di fare tutto questo "manualmente" è possibile usare un tool che consente di creare automaticamente tutti i link necessari e di installa la Java Virtual Machine se necessario. Questo tool è presente in BuilderOne, per assistere lo sviluppatore di un progetto nel creare il pacchetto di installazione.

 

Il pannello Package

Dopo aver creato il progetto è necessario creare il pacchetto di installazione, per fare questo clicchiamo sul pannello Package.

 

Step1: Cartella del CD

Per prima cosa è necessario indicare la cartella dove creare tutti i file necessari per l'installazione. Di default tale cartella è ...\LabelOne\CD_NomeProgetto, ma è possibile assegnarle un qualunque altro nome.

 

Step2: Frame di partenza

Assegnare il frame di partenza (Main), cioè quel frame in cui entremo all'esecuzione del progetto e da cui si parte per accedere a tutti gli altri eventuali frame.

 

Step3: Scegliere il logo

Quando l'installer viene eseguito, nella sua finestra mostrerà un'immagine che può essere sostituita. In realtà possono essere usate più immagini. In tal caso l'installer le scorrerà dalla prima all'ultima allo scopo di fare una breve presentazione del progetto oppure dell'azienda produttrice. Per aggiungere un'immagine basta premere sul pulsante "+".

 

L'immagine deve essere 400x300 pixel altrimenti verrà tagliata o non occuperà l'intero spazio disponibile. Del testo descrittivo può essere aggiunto ad ogni immagine. Questo consentirà di descrivere la sequenza.

 

Step4: Opzioni di esecuzione

Il settaggio delle opzioni di esecuzione consente di terminare la configurazione dell'installer

ResizeWindow. Il progetto si adatterà alle dimensione dello schermo del pc in cui è eseguito. Questa opzione è molto comoda, ma richiede potenza di calcolo della sceda video. Se il Pc è dotato di poche risorse, conviene provare a realizzare i frame della dimesione giusta e di non usare questa opzione.

Run in Full Screen. Esegue il progetto a tutto schermo.

 

Step5: Creare/Aggiornare i File

Tutte le volte che si cambia qualcosa al progetto, si abilita il tasto per aggiornare i file. Se tale tasto non viene premuto i cambiamenti andranno persi alla chiusura del programma. La creazione e l'aggiornamento dei file richiede alcuni secondi. Al termine un messaggio indicherà quanto tempo è stato necessario.

 

Step6: Testare il risultato

Per "vedere" come si comporterà l'installer è possibile usare il pulsante Test. Tale pulsante è disabilitato se non è mai stato usato il pulsante dello step5. A questo punto copiare tutto il contenuto della cardella CD_NomeProgetto nel CD. Il file Autorun consente di eseguire automaticamente l'installer quando il CD è inserito nel PC. Il file Autorun non funziona se si usa una chiavetta USB. Ma è comunque possibile copiare tutti i file su una chiavetta USB e poi cliccare due volte su Setup.exe per eseguire manualmente l'installer.
