Installazione

Requisiti di Sistema

Per l'uso di LabelOne e' necessaria la Java Runtime Environment (JRE) versione 1.6 o successiva. E' possibile trovare questa sul CD-ROM o una nuova versione sul sito web Sun. Le richieste dell'hardware, sono le stesse richieste da JRE.

Se lavori in Windows le richieste sono:

WindowsXp (+SP3)

JRE 1.6 o successiva

512Mb Ram

Connessione Internet (necessaria per l'attivazione del programma e per ottenere successivi aggiornamenti)

 

Per installare il software 

Inserisci  il CD_ROM nel driver del tuo PC e segui le istruzioni.

Se non premi sul pulsante "Salta Intro", potrai assistere ad una presentazione di LabelOne. Alla fine della presentazione, automaticamente andrai nella finestra successiva.

Se nel tuo sistema non e' installata la JRE, l'installer la installera' e poi installera' LabelOne.

Alla fine dell'installazione, LabelOne verra' avviato automaticamente e ti verra' richiesto di inserire il Codice di Attivazione. Se non possiedi il codice di attivazione, potrai avviare LabelOne in modalita' demo

Nota. Se la finestra di installazione non parte automaticamente, puoi cercare il file Setup.exe  nel CD_ROM e avviarlo manualmente.
